# Installation

1. Extract the ZIP.
2. Open `website`.
3. Copy every file and folder inside `website`.
4. Paste into the root of the local `maxdrill-website` repository.
5. Select **Replace all files**.
6. In GitHub Desktop confirm that many files appear under **Changes**.
7. Commit:
   `Fix MAXDRILL Public Corporate Build 001B`
8. Click **Push origin**.
9. In Cloudflare Pages verify the newest deployment is successful.
10. Open:
    `https://maxdrilltech.com/?build=001b`
11. Press **Ctrl + F5**.

The bottom-right corner must show `BUILD 001B`.
