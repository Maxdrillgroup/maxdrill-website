# Installation — MAXDRILL BUILD 001

1. Extract the ZIP.
2. Open the folder `website`.
3. Copy everything inside it.
4. Paste into the root of your local `maxdrill-website` repository.
5. Replace the existing files.
6. Open GitHub Desktop.
7. Commit with:
   `Launch MAXDRILL Public Corporate Build 001`
8. Click **Push origin**.
9. Wait for Cloudflare Pages deployment.
10. Refresh `maxdrilltech.com` with **Ctrl + F5**.

## Verify
Public navigation must show only:
- Decision Intelligence
- Research
- Academy
- Company
- Contact

The following paths must display a private-development message:
- `/store/`
- `/portal/`
- `/checkout/`
- `/auth/login/`
